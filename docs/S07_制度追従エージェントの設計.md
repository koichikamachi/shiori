## 0　これは何を埋めるものか

S06で空欄になったのは、審査基準②「自律性・エージェントらしさ」だけである。宿題1がその答えであり、同時に必須要件②（Gemini／ADKの利用）も満たす。**画面より先に作る。**

そして、このアプリの自律性をどこに置くかは、S04で一度決めてある。

> **利用者の事情を判断させない。地図そのものを最新に保つ仕事に、自律を置く。**

手続の案内は決定論的な計算がやる。エージェントは、その計算が読む**地図の側**を見張る。役割が重ならないので、「AIが法律の判断をしている」という一番弱い形にならない。

## 1　仕事の中身

いま `legal_metadata.needs_check` に、**確かめていない項目が66件**ある（ノード64件のうち62件が `SELF_REVIEWED`、`SOURCE_VERIFIED` は2件だけ）。これが入力である。

エージェントは1件ずつ、こうする。

```
いま何を主張しているか（ノードの記述）を受け取る
      ↓
公的機関のサイトを自分で探す
      ↓
そのページを読む
      ↓
いまの記述と突き合わせる
      ↓
「古い／変わっていない／分からない」と、根拠と、直す案を出す
      ↓
    人が決める
```

**JSONは書き換えない。案を出すところで止まる。** 書き換える道具そのものを持たせない。

---

## 2　出す答えは、成功と失敗の二値ではない

ここが設計の要である。制度を調べる仕事は、**空振りのほうが多い。** 空振りを失敗として潰すと、エージェントは何かを見つけたふりをする。だから答えを五つに分ける。

| 答え | 意味 | そのあと |
|---|---|---|
| `UNCHANGED` | 一次資料で確かめた。記述は現行のまま | `SOURCE_VERIFIED` へ上げる案を出す |
| `CHANGED` | 記述が古い。根拠あり | 直す案を出す。**人が見る** |
| `AMBIGUOUS` | ページはあるが、この点をはっきり書いていない | 専門家に聞く項目として残す |
| `NOT_FOUND` | 公的なページが見つからない | 人に投げる（自治体差など） |
| `UNCERTAIN` | 根拠が要件を満たさなかった | 何も変えない。次回に回す |

**確かめられなかったことを、確かめたように見せない。** これはS02とS03で決めた `verification_status` の考え方そのものである。エージェントにも同じ規律を課す。

とくに `NOT_FOUND` は、自治体にきちんとしたサイトがない場合の答えである。そこでエージェントは黙って失敗するのではなく、**「国の制度としてはここまで。この先は自治体ごとに違うので電話で確かめること」**と出力する。使えない場所を、使えないと言えることが出力になる。

## 3　出力の形

`data/proposals/YYYY-MM-DD/<node_id>__<n>.json` に書く。`data/nodes/` には触らせない。

```json
{
  "check_id": "SELF_BIZ_SUCCESSION_TAX#1",
  "node_id": "SELF_BIZ_SUCCESSION_TAX",
  "claim": "適用期限は2027-12-31であり、延長されていない",
  "verdict": "UNCHANGED",
  "confidence": "HIGH",
  "checked_at": "2026-09-02",
  "evidence": [
    {
      "url": "https://www.chusho.meti.go.jp/zaimu/shoukei/...",
      "publisher": "中小企業庁",
      "page_date": "2026-04-01",
      "quote": "（ページから一字一句そのまま）",
      "quote_verified": true
    }
  ],
  "proposed_patch": {
    "json_pointer": "/legal_metadata/verification_status",
    "current": "SELF_REVIEWED",
    "proposed": "SOURCE_VERIFIED",
    "rationale": "一次資料で確認した"
  },
  "risk_if_wrong": "古いままなら、まだ間に合う人に『手遅れです』と案内する",
  "human_review_required": true,
  "escalation": null
}
```

`human_review_required` は**常に true** である。false になる道を作らない。

## 4　嘘を機械で落とす

エージェントの出力は、そのまま信じない。人が見る前に、**LLMを使わない Python が落とす。** ここが実装品質の見せどころでもある（審査基準③）。

| 関門 | 落ちる条件 |
|---|---|
| **出どころ** | `go.jp` `lg.jp` 以外のドメインは根拠として認めない |
| **引用の一致** | 引用文が取得ページに一字一句なければ、その根拠を捨てる |
| **根拠ゼロ** | 残った根拠が0件なら、`CHANGED` を名乗れない。`UNCERTAIN` に落とす |
| **日付** | `page_date` が未来、または `checked_at` と食い違えば落とす |
| **書き換え先** | `json_pointer` が既存の場所を指していないか、型が変わるなら落とす |
| **格上げ禁止** | `EXPERT_VERIFIED` を提案したら落とす。**人以外がここへ上げる道はない** |
| **道具** | エージェントは `data/nodes/` への書き込み道具を持たない |

引用の一致を機械で見るのが、いちばん効く。**取ってきたページに実際に載っている文字列でなければ、根拠として存在しない。** もっともらしい要約は、ここで全部落ちる。

## 5　組み立て（ADK）

役を分ける。一人にまとめると、探した本人が「見つけた」と言い張る。

| 役 | 仕事 | 道具 |
|---|---|---|
| 探す役 | この主張を確かめられる公的ページを探す | 検索 |
| 読む役 | ページを取り、その箇所を抜き出す | 取得 |
| 突き合わせる役 | いまの記述と比べ、答えを五つから選ぶ | なし |
| **崩す役** | わざと反対から見る。「これは特例措置か一般措置か」「このページは古い版ではないか」「計画の期限と、渡す期限を混ぜていないか」 | 検索 |
| 書く役 | 決めた形に整えて書き出す | 案の書き出しのみ |

**崩す役を独立させるのは、実際に一度助けられたからである。** 事業承継税制で、計画の提出期限は延びていたが、株を渡す期限は動いていなかった。ひとつなぎで読むと「延長された」で終わる。ここを分けて見に行かせる。

## 6　できたと言えるのはどこか（テスト）

**APIの鍵がなくても回るテストを本体にする。** 関門はすべて Python なので、そのままテストできる。

| テスト | 見るもの |
|---|---|
| 公的でないドメインの根拠が捨てられるか | 出どころ |
| ページにない引用が捨てられるか | 引用の一致 |
| 根拠が全部落ちたとき `CHANGED` が `UNCERTAIN` に落ちるか | 根拠ゼロ |
| `EXPERT_VERIFIED` の提案が拒まれるか | 格上げ禁止 |
| 存在しない `json_pointer` が拒まれるか | 書き換え先 |
| **事業承継税制の凍結ページで、二つの期限を混ぜないか** | 崩す役 |

最後の1本は、2026年8月時点の中小企業庁のページを固定して置き、**「計画は延びた／渡す期限は動いていない」を両方言えたときだけ通す。** ここが通らないうちは、動画のあの場面を撮らない。

そして S03 の決まりどおり、テストを書いたら**わざと壊して、捕まるかを見る。** 9月2日に実際にやった結果が下である。

| わざと壊したところ | 落ちたテスト |
|---|---|
| `http://` も公的として通す | 1本 |
| 引用の一致を見ない | 3本 |
| 短すぎる引用も根拠にする | 1本 |
| 根拠ゼロでも `CHANGED` を名乗れる | 1本 |
| 触ってよい場所の制限をやめる | 1本 |
| `EXPERT_VERIFIED` を許す | 1本 |
| 値の型が変わってもよいことにする | 1本 |

七つとも捕まった。素通りしたものは無い。

## 9　やらせないこと

- 利用者の事情を判断すること
- `data/nodes/` を書き換えること
- 公的でないサイトを根拠にすること
- 「たぶんこうです」と言うこと（言えないときは `UNCERTAIN`）
- `EXPERT_VERIFIED` に上げること

**この五つを守れているかは、コードを読めば分かる形にしておく。** 守っていると書くのではなく、道具を持たせないこと、関門で落とすことで示す。
