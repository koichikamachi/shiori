0　これは何を上げるのか

server.py は、地図を配るだけの小さなサーバである。

  • 入口（/）に、16通りの場面が並ぶ
  • 場面を押すと（/map/surv-day10-nomemo）、その場で判定エンジンを回して路線図を組んで返す
  • 「今日」はURLで受ける（?today=2026-09-05）。サーバは何も覚えない
  • ログインが要らない。Cookie を出さない。書き込む先がない

あらかじめ書き出したHTMLを配るのではなく、その場で組んで返す。 理由は二つある。データを直したら次に開いた人にはもう直っていること。そして、決定論のエンジンがクラウドのうえでも同じ答えを出すことを、URLそのものが示すこと。 同じURLを二度開けば、同じ地図が出る。

保存しないという方針と、Cloud Run の性質が、たまたま同じ形をしている。 インスタンスが消えても失うものが無い。審査員がURLを開いた瞬間に動く（提出物の条件にある「ログイン必須は避けてください」を、はじめから満たしている）。

1　まず手元で動かす（今晩やっておく）

cd "C:\Users\MyProjectsOnWin\9-5ハッカソン開発準備"
pip install -r requirements-web.txt
python -m uvicorn server:app --port 8080

ブラウザで http://127.0.0.1:8080 を開く。

  • 入口に16通りが並ぶ
  • どれか押すと地図が出る
  • 駅を押すと右から説明が出る
  • 「← ほかの場面を見る」で戻れる

止めるのは Ctrl+C。

ここが動けば、Cloud Run でも動く。 同じ Dockerfile で動かすからである。

2　会場で打つコマンド（五つ）

① 入っているか確かめる

gcloud --version

無ければ入れる（Google Cloud CLI）。

② 入る

gcloud auth login
gcloud config set project <プロジェクトID>

③ 使うものを有効にする

gcloud services enable run.googleapis.com cloudbuild.googleapis.com artifactregistry.googleapis.com

④ 上げる

gcloud run deploy shiori --source . --region asia-northeast1 --allow-unauthenticated

途中で聞かれることに答える。数分かかる。

終わると Service URL が出る。それが提出するURLである。

⑤ 確かめる

gcloud run services describe shiori --region asia-northeast1 --format="value(status.url)"

出たURLを、スマートフォンで開く。 ログインを求められないことを、自分の目で見る。

3　詰まったときに見るところ

症状 見るところ
起動しない gcloud run services logs read shiori --region asia-northeast1 --limit 50
502 が出る $PORT で待っているか。Dockerfile の CMD を確かめる
ビルドが失敗する gcloud builds list --limit 3 → gcloud builds log <ID>
認証を求められる --allow-unauthenticated を付け忘れている
リージョンが違うと言われる --region asia-northeast1 を毎回付ける

会場で聞くときは、症状ではなくログを見せる。 そのほうが速い。

4　上げ直すとき

同じコマンドをもう一度打つだけである。

gcloud run deploy shiori --source . --region asia-northeast1 --allow-unauthenticated

データを直したら、上げ直せばそれだけで反映される。 ページはその場で組んでいるので、HTMLを書き出す手間はない。

5　お金のこと

  • Cloud Run はリクエストが来ないあいだは動かない設定が既定である。誰も開かなければ、ほぼかからない
  • 予算アラートを先に置く。 これは会場でいちばん先にやること
  • 上限を決めておくなら
gcloud run services update shiori --region asia-northeast1 --max-instances=3

6　まだ上げないもの

  • Gemini API キーは、この段階では要らない。 地図を配るだけなので、AIを呼ばない
  • 鍵が要るようになったら、環境変数に直書きせず Secret Manager に置く
  • .env は .gitignore が無視する。tests/test_no_secrets.py が commit 前に見張っている

7　この日の合格ライン

  • [ ] gcloud run deploy が終わって、URLが出た
  • [ ] そのURLをスマホで開いて、地図が出た
  • [ ] ログインを求められなかった
  • [ ] URLを控えた

四つ揃えば、10月の最大の不確かさが一つ消える。 あとは中身を良くするだけになる。
