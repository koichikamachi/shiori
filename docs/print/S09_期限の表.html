2　相続するか、放棄するか、限定して承認するかを決める

遺された人の画面に出ます
期間の長さ 3 か月
いつから数えるか 自己のために相続の開始があったことを知った時
画面での書き方 「自己のために相続の開始があったことを知った時」
過ぎたときの扱い 過ぎたら、その手続そのものができなくなる
いまの確かめ具合 一次資料で確かめた（2026-09-04）
典拠 裁判所「相続の放棄の申述」
出典 https://www.courts.go.jp/saiban/syurui/syurui_kazi/kazi_06_13/index.html
相談先として案内している職種 弁護士

数え方について書いていること　月で数える。日数に換算しないこと。初日は算入せず、応当日の前日に満了する（民法140条・143条2項）。応当日のない月は末日。例：9月10日に知ったなら、満了は12月10日。

根拠として持っている記述

裁判所「相続の放棄の申述」より逐語：「自己のために相続の開始があったことを知ったときから3か月以内にしなければならない」。申述人は相続人（未成年者・成年被後見人の場合は法定代理人が代理して申述）。費用は収入印紙800円分（申述人1人につき）と郵便切手。民法第915条第1項（熟慮期間）、第921条第1号（処分による法定単純承認）・第2号（期間経過による法定単純承認）・第3号（隠匿・私的消費）。なお同ページには民法の条番号の記載がないため、条番号は別に確かめること。

画面に赤い帯で出る文（そのまま）

【事実】この期間を過ぎると、原則として、借入や保証をそのまま引き継ぐことになります。

【ただし】ただし、借金の存在をまったく知らなかった場合（督促状が届いて初めて知った場合など）には、期間の数え始めが後ろにずれると判断された例があります。期限を過ぎたと思っても、あきらめる前に弁護士に相談してください。

期限を過ぎているときに出る文（そのまま）

放棄と限定承認の申述は、この期間が過ぎるとできません。過ぎた場合、法律上はすべてを相続したもの（単純承認）として扱われます。
ただし、財産がまったくないと信じていて、そう信じたことに相当な理由があり、調べることが著しく難しかったといえる場合には、数え始めを「借金の存在を知った時」とする扱いがあります。
逆に、故人と同居していた、預金や不動産の存在を知っていた、郵便物を容易に確かめられた、すでに遺産の一部を受け取っていた——こうした事情があると、「調べなかっただけ」と判断されることがあります。知らなければいつでも放棄できる、という制度ではありません。
いま請求書が届いているなら、今日これだけはしてください。届いた封筒と書類を、日付が分かる形で残す。支払う約束をしない。借金があると認める返事をしない。遺産に手を付けない。そのうえで、日を置かずに弁護士に相談してください。

こちらで、まだ確かめられていないこと

  • ★重要★ 熟慮期間の起算点がずれる場合の判例の射程
  • 限定承認の要件（相続人全員の同意）と、みなし譲渡課税の扱い
  • 知らなかった負債が判明した場合の熟慮期間の起算点（最高裁昭和59年4月27日判決の射程）
  • 最高裁昭和59年4月27日判決の射程（相当な理由が認められた事案と、認められなかった事案の分かれ目）
  • 家庭裁判所の受理後に、民事訴訟で放棄の効力が否定された裁判例の有無と傾向
  • 熟慮期間の満了日の計算（初日不算入・応当日の前日）を、家庭裁判所の実務で確かめる
  • 民法第915条第1項・第921条各号の条文そのものを e-Gov 法令検索で確かめる（裁判所のページには条番号の記載がない）

3　調べが終わらないときは、期間を延ばす

遺された人の画面に出ます
期間の長さ 3 か月
いつから数えるか 自己のために相続の開始があったことを知った時
画面での書き方 「自己のために相続の開始があったことを知った時」
過ぎたときの扱い 過ぎたら、その手続そのものができなくなる
いまの確かめ具合 一次資料で確かめた（2026-09-04）
典拠 裁判所「相続の承認又は放棄の期間の伸長」
出典 https://www.courts.go.jp/saiban/syurui/syurui_kazi/kazi_06_25/index.html
相談先として案内している職種 弁護士

数え方について書いていること　伸長の申立ては、熟慮期間が終わる前に行う必要がある

根拠として持っている記述

裁判所「相続の承認又は放棄の期間の伸長」より逐語：「申立ては，自己のために相続の開始があったことを知った時から3か月以内にする必要があります。」申立人は「利害関係人（相続人も含む。）」および「検察官」。費用は「収入印紙800円分（相続人1人につき）」と「連絡用の郵便切手」。この一文が、gate=CLOSES の根拠である。過ぎたら申立てそのものができない。民法第915条第1項ただし書（期間の伸長）。

画面に赤い帯で出る文（そのまま）

【事実】期間を延ばす申立ては、3か月が過ぎる前にしかできません。1日でも過ぎると、法律上すべてを相続したものとして扱われ、申立てそのものができなくなります。家庭裁判所があとから救うことはできません。

【ただし】ただし、この申立ては安く、早くできます。相続人一人につき収入印紙800円と、連絡用の郵便切手だけです。通常は1か月から3か月ほど延ばせます。迷ったら、期限が来る前にまず延ばしてください。

期限を過ぎているときに出る文（そのまま）

この申立ては、熟慮期間が終わる前でなければできません。ただし、いつから数え始めるかは、事情によって後ろにずれると判断された例があります（借金の督促状が届いて初めて相続を知った場合など）。過ぎていると思っても、あきらめる前に弁護士に相談してください。

こちらで、まだ確かめられていないこと

  • 再度の伸長が認められる場合の要件
  • 申立ての時点で、どこまで調べが進んでいる必要があるか（実務上の扱い）
  • 熟慮期間が過ぎたあとの伸長申立てが、実務上どう扱われるか（却下されるか、起算点の主張とあわせて受理される余地があるか）
  • 民法第915条第1項ただし書の条文そのものを e-Gov 法令検索で確かめる

数え方について書いていること　計画の提出期限は2027-09-30。渡す期限は2027-12-31。あいだが3か月しかない。急所は計画ではなく、渡すほうの期限である。

根拠として持っている記述

租税特別措置法第70条の7の5（贈与）、同第70条の7の6（相続）。令和8年度税制改正の大綱により、特例承継計画の提出期限を1年6月延長（令和8年3月31日→令和9年9月30日）。適用期限（令和9年12月31日）は延長されていない。

画面に赤い帯で出る文（そのまま）

【事実】計画を出せる期限は令和9年9月30日まで延びましたが、実際に株を渡す期限は令和9年12月31日で変わっていません。あいだは3か月しかありません。計画を出しても、その日までに渡し終えていなければ、この特例は使えません。

【ただし】ただし、期限は法改正で動きます。いまの期限と、自社が要件を満たすかを、まず税理士に確かめてください。間に合わない場合にも、一般措置を使う、株価を下げる手立てを取る、役員退職金を組み合わせる、持株会社にして承継の道筋を変えるなどの方法があります。効き方も副作用も違うので、どれが自社に合うかは税理士と決めてください。

期限を過ぎているときに出る文（そのまま）

特例措置の期限が過ぎても、一般措置（納税猶予）は残ります。ただし要件と、猶予される割合が異なります。どちらが使えるかは、税理士に確かめてください。

こちらで、まだ確かめられていないこと

  • 要件（後継者の数、雇用、代表就任など）は未確認。税理士に確かめる箇所とする。
  • 適用期限（令和9年12月31日）が今後さらに延長されないか、年に一度は確かめる。

相談先として案内している職種 税理士

数え方について書いていること　計画の提出期限は2028-09-30。渡す期限は2028-12-31。法人版とは期限が違う。混同しないこと。

根拠として持っている記述

租税特別措置法第70条の6の8（贈与）、同第70条の6の10（相続）。令和8年度税制改正の大綱により、個人事業承継計画の提出期限を2年6月延長（令和8年3月31日→令和10年9月30日）。適用期限（令和10年12月31日）は延長されていない。特定事業用宅地等について小規模宅地等の特例を受ける者がある場合、この特例は使えない。

画面に赤い帯で出る文（そのまま）

【事実】計画を出せる期限は令和10年9月30日まで延びましたが、実際に事業用資産を渡す期限は令和10年12月31日で変わっていません。その日までに渡し終えていなければ、この特例は使えません。

【ただし】期限は法改正で動きます。個人版は法人版と期限が違います。いまの期限と要件を、税理士に確かめてください。

期限を過ぎているときに出る文（そのまま）

個人版には、法人版のような一般措置がありません。この期限が過ぎると、この特例は使えなくなります。ただし、特定事業用宅地等についての小規模宅地等の特例など、別の手立てが残っている場合があります。税理士に確かめてください。

こちらで、まだ確かめられていないこと

  • ★ 国税庁タックスアンサー No.4153 は、計画の提出期限を令和8年3月31日のままにしている（令和8年度改正前の記載）。改訂されたら差し替えること。
  • 小規模宅地等の特例との併用不可が特定事業用宅地等に限られるのか、特定居住用宅地等とは併用できるのかを確かめる。
  • 租税特別措置法の条番号（第70条の6の8・第70条の6の10）を条文で確かめる。
