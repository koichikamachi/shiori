## 1　`gcloud` を入れる（10分）

### やること

ブラウザで **`https://cloud.google.com/sdk/docs/install`** を開き、Windows 用のインストーラを落として実行する。

### 画面に出ること

- インストーラの画面が出る。**既定のままで進めてよい**
- 最後に「Run `gcloud init`」のようなチェックが出ることがある。**チェックは外してよい**（あとで手で打つ）

### 終わったら

**PowerShell をいったん閉じて、開き直す。** これをしないと次の行が「そんなコマンドはありません」と言われる。

```
gcloud --version
```

**出るはずのもの**

```
Google Cloud SDK 5xx.x.x
bq 2.x.xx
core 2026.xx.xx
gcloud-crc32c 1.x.x
gsutil 5.xx
```

**バージョンが並んで出れば、一段目は合格。**

## 3　プロジェクトを作り、請求先を紐づける（10分）

**ここはブラウザの操作である。**

### ① クーポンのメールを開いておく

Zenn から届いたメール（9月3日、件名「…参加特典クーポンが発行されました」）にコードがある。

- **$300 の Google Cloud クレジット**
- **登録期限 2026年10月20日**（応募締切の10月15日より後なので、期間は足りている）

**コードは商品券と同じである。** 持っている人が使える。**Zenn の記事、GitHub、Discord には貼らない。この紙にも書き写さない。** 今晩のうちに登録してしまえば、先生のアカウントに紐づいて他人には使えなくなる。**それが一番の対策である。**

**プロジェクトを作る前に、メールのリンク（ハッカソンページ）で利用条件を一度見ておく。** クレジットは特定の請求先アカウントに載るので、先に別のものを作ると載せ替えの手間が出る。

### ② プロジェクトを作る

- `https://console.cloud.google.com` を開く
- 画面のいちばん上、Googleのロゴの右に**プロジェクト名を選ぶ枠**がある。押す
- 右上の **「新しいプロジェクト」** を押す
- 名前を付ける（`shiori` など）。**プロジェクトID**が自動で決まる。**このIDを控える**（`shiori-472301` のような形）
- 「作成」。数十秒かかる

### ③ 請求先アカウントを紐づける

- 左のメニュー（三本線）から **「お支払い」**
- 「請求先アカウントをリンク」。無ければ作る（カードの登録が求められる）
- **クーポンコードを登録する。** メールの案内のリンクから入るのが確実
- 登録できると、請求先アカウントの残高に **$300 のクレジット**が載る

### ④ 予算アラートを置く（これを飛ばさない）

- 「お支払い」→ **「予算とアラート」** → 「予算を作成」
- 金額を決める（**まずは 3,000円**でよい。少なすぎるくらいでよい。$300 のクレジットがあっても、置く）
- 50%・90%・100% で**メールが来る**設定にする

**クレジットがあっても置く。** クレジットが尽きた瞬間からカードに移るので、見張る意味は変わらない。

## 7　上げる（5分）


- **`Allow unauthenticated invocations to [shiori] (y/N)?`** → **`y`** と打つ
  （これで、ログイン無しで誰でも開けるURLになる。審査の条件である）
