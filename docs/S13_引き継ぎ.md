## 2　9月に決めたことのうち、S03 に入っているもの

すべて `docs/S03_エンジンの決めごと.md` に規則として書いてある。**再議論しないこと。**

- **期限には二種類ある** … `deadline.gate` が `STAYS_OPEN`（既定。死亡届・相続登記・相続税・準確定申告）か `CLOSES`（熟慮期間とその伸長、事業承継税制）。`CLOSES` が過ぎたものは「今日の3件」にも赤い帯にも出さず、破線の灰色の駅として**「期間が過ぎている可能性」**とだけ書き、`closed_note` と相談先を必ず添える
- **済んだ駅に時計を出さない** … `status == DONE` なら `days_left` は `None`
- **「およそ」** … 知った日を聞いていないために死亡日で代用した時計は「**およそ** あと82日」と書く。3か月は**自分が相続人になったと知った日**から、相続人ごとに走る
- **三か月は暦で数える** … 初日不算入、応当日の前日に満了（民法140条・143条2項）
- **1日目に聞く** … `ask_order.DAY_ONE`。質問は**最大3問**（テストで縛る）。答えないことを選べる。答えなければ「およそ」になる
- **赤い帯に出す三条件** … 取り返しがつかない／今日、動かせる／こちらが言える。**三つ全部が揃ったときだけ**
- **絵にするときも三区分を混ぜない** … 通る道は駅と線、**霧は駅にしない**（別の折り畳みで「『通らなくて済む』という意味ではありません」を添える）、通らない道も駅にしない。丸ごと無い流れにはレーンを引かない。**内部の識別子を画面に出さない。`**` を利用者に見える文に混ぜない**

## 5　地雷（同じところで転ばないために）

**ファイルの受け渡し**

- 配達に失敗したら、**その場で送り直す。** できなければ次の返事の冒頭に未達の一覧を書く。書き込んだあとは **grep で中身を確かめる**
- 置き場所は `9-5ハッカソン開発準備` の直下である。**`shiori\` というサブフォルダを作らない**（一度やって、16ファイルが迷子になった）

**git**

- **この会話の側から、フォルダの中で git を走らせない。** `index.lock` が残り、こちら側からは消せない。状態を知りたければファイルを読むだけにする。書き込みを伴う git は、先生の PowerShell だけが持つ
- `--amend` が使えるのは push する前だけである

**言葉づかい（対外的な責任に関わる）**

- **商品名を書かない**（テストで縛ってある）
- `verified_by` は**内部で確かめた記録**であって、対外的な専門家保証ではない
- **制度の事実は断定し、その人の事案の結論は断定しない**
- 弁護士でない者・税理士でない者が、法律行為の意見を述べ税務相談に答えることは禁じられている。**文言はそこを越えない**

**秘密**

- **APIキーを会話に貼らない**（環境変数と Secret Manager で扱う）
- クーポンコード等を、GitHub・Zenn・Discord・プロジェクト内の紙に書かない
- `tests/test_no_secrets.py` が毎回見張っている

**簿記のレンズは、頼まれたときだけ使う。**

## 7　もう一本のこと
